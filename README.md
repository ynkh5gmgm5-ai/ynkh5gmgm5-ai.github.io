# 我的个人网站

这是我的个人网站，主要记录我对 HiFi 市场的观察、研究与思考，也分享耳机和相关设备的主观听感与使用体验。

网站内容包括：

- HiFi 市场研究：品牌、产品、渠道、用户需求与市场趋势
- 耳机主观测评：头戴式耳机、入耳式耳机与播放器的听感记录
- 听音笔记：门店、展会和现场试听体验
- 摄影与个人记录

这里的测评以个人长期使用和主观感受为基础，不追求绝对结论，更希望呈现真实、具体的使用情境。

网站地址：[ynkh5gmgm5-ai.github.io](https://ynkh5gmgm5-ai.github.io/)

## 技术栈

- Astro
- React
- Tailwind CSS
- GitHub Pages

## 本地开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
